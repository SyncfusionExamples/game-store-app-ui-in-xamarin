# Game Store UI in Xamarin Forms


This Xamarin.Forms sample demonstrates how to create a modern and visually engaging **Game Store Application UI** using Xamarin.Forms and Syncfusion controls. The sample showcases a product details page commonly found in mobile gaming marketplaces, allowing users to browse game information, view ratings, read descriptions, explore related titles, and purchase games through an intuitive interface.

The application is designed with a clean and immersive layout that highlights featured game content. A large hero image is displayed at the top of the page, immediately capturing user attention and providing a visually appealing introduction to the selected game. Below the image, the application presents detailed game information including the title, publisher details, overview description, ratings, and pricing information.

The game overview section provides users with essential information about the selected game, helping them make informed purchasing decisions. A favorite button is included, allowing users to mark games for future reference. This functionality is commonly used in digital storefronts to help users build personalized wish lists or collections of preferred games.

The sample utilizes Syncfusion's **SfRating** control to display game ratings in a professional and user-friendly manner. Ratings are presented in a read-only format, making it easy for users to evaluate games based on reviews and popularity. The rating component provides a familiar experience commonly seen across gaming platforms and online marketplaces.

A collection of related games is displayed using a CollectionView, enabling users to discover additional titles. Each game entry contains an image, game title, status information, and rating details. This approach helps improve user engagement by encouraging exploration of additional content within the application.

The bottom section of the page contains pricing information and a prominent purchase action. Original and discounted prices are displayed together, helping users identify promotional offers and discounts. An "Add to Cart" button provides a clear call-to-action for initiating the purchasing process.

## Application Workflow

1. The application displays a featured game with a large banner image.
2. Users can review the game title and publisher information.
3. An overview section provides a description of the game.
4. Ratings are displayed using Syncfusion's rating control.
5. Related games are shown in a scrollable list.
6. Users can compare ratings and game details.
7. Price information is displayed with discount indicators.
8. Users can add the game to their shopping cart.
